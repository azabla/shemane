# Robit Handloom — Complete Documentation Pack

**Version 1.0 — 11 November 2026**

This pack replaces the previous homepage-hero-only specification. It now covers the entire proposed Robit Handloom experience and operations, with a selected **Liberu Ecommerce** foundation, an implementation procedure for AI coding agents and a Docker-first development workflow.

## What is inside

| File | Purpose |
|---|---|
| `ROBIT_HANDLOOM_COMPLETE_IMPLEMENTATION_MANUAL.pdf` | Single combined printable guide containing all main specifications |
| `ROBIT_HANDLOOM_COMPLETE_MASTER_BLUEPRINT.md` | Product, design, frontend, operational, security and launch master spec |
| `ROBIT_HANDLOOM_AI_EXECUTION_GUIDE.md` | Exact AI-agent rules, 18 milestone runbook and first prompt |
| `ROBIT_HANDLOOM_DATA_AND_API_CONTRACTS.md` | Data model, extension tables, relationships, invariants, APIs and events |
| `ROBIT_HANDLOOM_DOCKER_DEVOPS_RUNBOOK.md` | Git and Docker setup, hot reload, operations, environments, CI, backups |
| `ROBIT_HANDLOOM_IMPLEMENTATION_BACKLOG.csv` | Prioritized engineering tasks with acceptance evidence and status column |

**These are implementation documents—not a shipped Laravel application.** The AI agent must inspect the user's own checked-out code at a known SHA and implement in phases. Payment-provider eligibility, actual artisan statements, original media, shipping availability and legal requirements require real-world verification.

## Recommended reading order

1. Read the PDF / master blueprint for complete business/product architecture.
2. Read the data/API contracts before designing migrations.
3. Use the Docker runbook to validate local environment and preserve volumes.
4. Place all Markdown files under `docs/robit/` in your own repository.
5. Give Codex the **First-turn prompt** in the AI guide. Begin with the upstream audit and Docker milestone, **not** the cinematic hero.
6. Track milestones using the CSV (import to GitHub Projects, Linear, Notion, etc.).

## Source foundation and caution

Liberu source: https://github.com/liberusoftware/ecommerce-laravel. Upstream describes the repo as MIT-licensed but also **pre-production and mid-migration**, with historically recorded security findings. Require a commit-pinned audit and no unverified live merchant/payment claims.
